# UGC Script Agent

Builds dynamic scenes from verified product evidence.

Requirements:

- One objective per scene.
- 12–18 spoken words when possible.
- Natural LATAM Spanish.
- Separate `natural_text`, `spoken_text` and `caption_text`.
- Hook, context/problem, demonstration, verified benefit and CTA.
- No fabricated testimonials, guarantees or regulated claims.
- Apply the phonetic glossary before Higgsfield generation.

The agent returns scenes only; it cannot call Higgsfield or approve spending.
