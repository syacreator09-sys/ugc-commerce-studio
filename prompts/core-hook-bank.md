# Core Hook Bank — UGC Commerce

Status: CANONICAL / PRINCIPAL
Owner: Cano Digital
Purpose: banco principal de estructuras de hook para UGC, afiliados, producto físico, software/herramientas y creativos de conversión.

## Regla

Antes de inventar un hook nuevo, intentar adaptar uno de estos patrones principales al producto, audiencia y evidencia disponible.

No tratar estos textos como claims automáticos. El remate debe respetar evidencia real del producto y las reglas de copy.

## Hooks principales

### 1. Curiosidad / Open Loop
- “¿Y si te dijera que…?”
- “Nadie te dice esto…”
- “Esto es lo que pasa cuando…”
- “Mira lo que le ocurre…”

### 2. Transformación / Consecuencia
- “Esto le pasaría a… si…”
- “Con tan sólo X…”
- “Si haces esto…”
- “Si sigues haciendo…”

### 3. Advertencia / Loss Aversion
- “Cuidado con usar…”
- “La mayoría lo hace mal.”

### 4. Precompra / Intención comercial
- “Antes de comprarlo, mira esto.”
- “No compres esto antes de ver…”
- “No pagues esta herramienta antes de ver esto.”

### 5. Descubrimiento / Deseo
- “Pensé que no lo necesitaba hasta que…”

## Prioridad para UGC de venta

Orden inicial de prueba recomendado:
1. Precompra / intención comercial
2. Curiosidad / open loop
3. Transformación / consecuencia
4. Advertencia / loss aversion
5. Descubrimiento / deseo

La prioridad es una hipótesis inicial, no un ranking universal. Validar con resultados reales por producto, canal y audiencia.

## Regla de test

Para comparar hooks:
- mantener producto, cuerpo, demo, duración y CTA tan constantes como sea posible;
- cambiar principalmente los primeros 0–3 segundos;
- registrar el hook exacto usado;
- medir retención inicial, CTR, CVR, pedidos/comisión cuando estén disponibles;
- multiplicar la familia ganadora antes de expandir a demasiados ángulos.

## Arquitectura del hook

Un hook puede tener tres capas coordinadas:
- hook visual;
- hook verbal;
- hook textual.

No duplicar innecesariamente la misma frase en las tres capas. Cada una debe sumar comprensión, curiosidad o prueba.

## Guardrails

- No inventar precio, descuento, stock, resultados, uso personal, testimonios o urgencia.
- No afirmar “lo probé”, “me funcionó”, “lo uso” o equivalentes sin evidencia real autorizada.
- No usar claims médicos o regulados no verificados.
- “X” siempre debe resolverse con un dato verificable o con una acción observable.
